# Biskiq · Smart Wall

A standalone browser prototype of spatial arrangement and revision. Reshape a
gallery wall while artworks, spacing and lighting respond to their relationships.
Compare revisions with ghost overlays and return to an earlier snapshot.

## Run it

From this directory:

```bash
npm install
npm run dev
```

Open <http://localhost:5175>. Try the wall presets or drag the wall's floor
handles, then adjust the artworks and lighting. `npm run build` type-checks and
builds the prototype.

This is accepted interaction evidence, with prototype-specific mechanisms. The
[prototype index](../README.md) explains the boundary between these demos and the
production product.
