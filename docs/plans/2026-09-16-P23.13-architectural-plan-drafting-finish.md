## 2. Implementation architecture

```
LayoutDocument (authored truth)
  → compileLayoutGeometry() (one compiler; curve/single-evaluator; sections/spans/openings)
  → PlanRenderModel (stable renderer-neutral source facts from canonical geometry:
     wall thickness + role, opening kind/center/tangent/normal, authored width,
     host thickness, floor polygons — never CSS px, zoom regime,
     or hysteresis)
  → plan-salience (transient: projected-size gates, hysteresis memories, gesture
     freeze → resolved screen-presentation decisions: Door normal-vs-small fallback,
     Window 1-vs-2 lines, silhouette aids, feature visibility)
  → plan-overlays (transient screen-space state consuming salience output:
     label candidates + sticky map, dimension lanes, snap feedback, intents,
     instrument zone — never document/history)
  → PlanSvg.svelte + chrome (paint only: world→screen for band/jambs;
     fixed-px ink/cues/handles/dimensions; tokens via --editor-plan-*)
```

- **Compiled geometry owns:** samples, sections, solid spans, openings (offset/width/center/tangent/normal/yaw), floor polygons, lengths (incl. arc), validity/diagnostics. Never pixels, dash counts, label positions. It does not expose a finished junction-correct Plan-band polygon contract — P23.13 renders the canonical physical-width projection from centerline/section truth and exposes insufficient-junction seams for P23.15.
- **Render model owns:** stable renderer-neutral source facts (listed above) + which primitives exist. No px math, no gate resolution, no hysteresis memory, no DOM.
- **Overlay/salience owns:** all px thresholds, hysteresis memories, sticky label map, frozen lanes/zones, snap presentation, intents. Keyed by canonical IDs; partitioned by lifetime — view-lifetime (semantic-zoom hysteresis memory, sticky Room-label placement; survives ordinary gestures and small pan/zoom), gesture-lifetime (frozen feature gates/control vocabulary, dimension lane, numeric ownership, instrument-zone bounds; clears on commit/cancel/tool change), bounded feedback lifetime (refusal annotation, ~1.2s or next deliberate action/Escape); geometry changes invalidate only affected derived state. None is serialized or enters document/history snapshots (follow the P23.12 `identityHighWater` precedent — derived marks outside the snapshot).
- **SVG owns:** paint mapping (band stroke from world width; ink/cues/handles/dims in fixed px with `vector-effect:non-scaling-stroke`; symmetric cue via `screenAt(center) ± perp·(cue/2)`).
- **Canonical interaction owns:** selection/history/transactions/validation/planners (`commitLayoutTransaction` five sites + three persistence seams stay the only durable paths; transient paths never `promoteLayoutIdentity` — CURRENT.md traps).
- **Forbidden:** second geometry truth, SVG topology repair/resampling, SVG hit resolver, cue-driven hit/snap/measure, persistent dims/annotations, hinge/swing schema, BIM/material/role semantics, shell restructuring (P23.14), junction-geometry fixes (P23.15).
