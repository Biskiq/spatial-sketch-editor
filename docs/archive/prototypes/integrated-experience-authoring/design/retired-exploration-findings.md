# Retired exploration findings (reconciliation evidence)

**Status:** reconciliation evidence for the coming repo-aware reconciliation and
implementation planning. **Not normative, not a ratified contract, not a MUST
list.** Source: the retired independent shell exploration
(`prototypes/biskiq-creator-shell-design-independent/`, removed PR #110),
chiefly its design-direction statement (§§4, 6, 12–13) and its index attention
filter. The prototype stays deleted; Git history is its record.

**How to read this.** Each finding is either PRESERVED — already carried by a
named surviving section, cited below instead of duplicated — or CONSIDERATION —
a genuinely unique, not-yet-ratified point the implementation plan should
decide explicitly (adopt, adapt, or reject with reason). Nothing here overrides
a ratified contract on disagreement.

## 1. Cross-type retrieval with occurrence identity — CONSIDERATION

Search should span World subjects, Presentations, Views, and Stops with type
and location in each result, including occurrence identity so repeated meaning
is disambiguated where it is found. Selecting a search result changes context;
applying a View remains an explicit inspection act. Partially overlaps the kept
commission brief (§6: search spans both lenses and explains out-of-view hits);
the cross-type + occurrence-identity scope is the unpreserved remainder.

## 2. Occurrence-aware disambiguation — PRESERVED

Shared Presentation versus Stop occurrence identity, carried by the Card while
the Deck shows occurrences, is accepted V2 direction: final synthesis §8
("Repeated Presentations").

## 3. Where-used surfaces — PRESERVED, with a CONSIDERATION remainder

Shared-edit reach with counts and affected lists is accepted V2 direction:
final synthesis §16 (Ask Rule) and commission brief §6 (scope header + reach).
CONSIDERATION remainder: reference surfaces revealed on demand only — no
permanent reference panels — including the retired idea of one temporary stack
anchor for Presentations sharing a focus (a retrieval surface, never a semantic
group or ownership claim).

## 4. Unresolved-reference repair choices — PRESERVED foundation, CONSIDERATION options

Foundation is ratified: F.1 (identity/reference — bindings keep original
identity with repair results intact; no silent name/proximity retarget) and
F.4 (compound acceptance admits explicitly-marked repairable unresolved
state). The kept commission brief §12 locks the behaviors (typed failure;
Relink / Remove use / keep explicit unresolved draft). CONSIDERATION
remainder: offering "subject-free meaning" and "new capture" as explicit repair
options alongside relink/remove/keep-draft.

## 5. Moved source invites framing review — PRESERVED, with an open calibration

Behavior is locked in the kept commission brief §12 (adaptive framings
recompute and surface the change; pinned framings flag `Review framing`;
Presentation identity and explanation untouched). Open calibration, carried as a
question not a rule: which World changes warrant a review notice without
producing noise.

## 6. Attention filtering instead of repair dashboards — CONSIDERATION

Repair visibility as a filter over the working surface (e.g. an
attention-only view with issue counts and an explicit return to full context),
rather than a permanent dashboard, timeline, or sidebar. Unique to the retired
exploration; decide explicitly during reconciliation.

## 7. Retained authoring context across lens moves — PRESERVED in part, CONSIDERATION remainder

Preserved: stage recipe and standpoint persist across lens switches (kept
commission brief §12); exact authoring context is restored on Preview exit
(final synthesis §19). CONSIDERATION remainder: latent meaning context — the
last relevant Presentation/occurrence stays latent while editing its World
subject and is restored on return; selecting an unrelated subject starts a new
meaning context instead of silently joining the old one; source edits never
trigger silent recapture.
