## Read the atlas as a bounded prototype

The atlas is a scenario player with a small functional opening-edit/history and view-lease demonstration. It is **not a miniature geometry implementation**. It does not execute the canonical compiler, persist a project, implement arbitrary pointer dragging, simulate all occlusion cases, or certify performance/accessibility. Blue opening grips focus the matching numeric field. Ceiling creation, curve-follow, joint resolution and host-deletion recovery are illustrated transitions; their messages are design behavior, not production transactions. Global Undo in the prototype demonstrates opening edits only; dedicated joint/deletion demonstration controls show those storyboard reversals separately.

Use the specification for the complete per-property gesture/validation rules and delivery distinction. In particular, source-specific Reveal, independently authored arch rise, coverage subtraction, ceiling joints and datum-safe reflected derivation require the architecture seams described there. Their feasibility is not proven by these SVGs.

The Navigator is a visual hierarchy with a working text filter; its rows are not a fully implemented canonical selection reducer. Scenario changes choose the relevant fixture target. Return and the 3D action preserve the demonstration target. Unimplemented shell actions are painted as labels rather than functioning application controls. Reviewer controls above/below the frame are atlas UI, not proposed editor chrome.

No other P26 submissions were opened or incorporated. Routing was changed only to make this unratified artifact discoverable. An unrelated pre-existing worktree deletion of `design/briefs/plate-scene-plan-1440x900.png` was observed on resuming this task and left untouched.
