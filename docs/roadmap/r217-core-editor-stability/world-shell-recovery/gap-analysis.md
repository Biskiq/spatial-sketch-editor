The linework diagnosis deliberately does **not** claim anti-aliasing is disabled:
the current renderer already requests `antialias: true`, and Canvas DPR is capped
at 1.5. First calibrate width, layering and duplicate visible strokes at the same
zoom. A DPR/coverage change needs a measured quality/performance reason; it is not
an automatic prerequisite or a license to rewrite drawing geometry.
