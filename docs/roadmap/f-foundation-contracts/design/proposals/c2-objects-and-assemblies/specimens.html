Reusable interaction & visual specimens

Specimens

The patterns the brief asks to be reusable: capability disclosure, scope and impact, inherited values, relationships and repair, plus state specimens for unavailable resources and a cancelled update. The static drawings show each pattern on its own. The live tiles load the real prototype straight into that state.

Live tiles each start a WebGL view, so they load only when you click them. Every one also opens full size in its own tab. Each is reached through the same actions a creator would use, via index.html?state=….

1. Capability disclosure

Three groups, always in the same order and always all shown — an empty group says “none”, it isn't hidden. The file's claims and Biskiq's checks are kept apart, and source and provenance sit one disclosure away.
