```text
Source / route   the closed stub (and section) or review item it comes from, and who owns it today

Options          FOLD     = goes into the pre-P23B.8 follow-up this doc establishes
                 P23B8    = keep / route as P23B.8 entry evidence
                 P26      = leave with P26 on its named route
                 WITHDRAW = stop carrying it
OWNER DECISION   left blank for the owner
Triggered edit   the exact README §SEQUENCE / current.md change an accepted option would make
```

