## 1. What S3 landed (exact skips only; every skip proved by the predicate it removes)

```text
(a) GROUP CHECK FIRST          `unionAuthorized` now runs before ANY geometry. It is a pure
                               component-label comparison — the same decision today's loop reaches
                               only after paying for both predicates — so a pair it refuses is
                               skipped first. UNCONDITIONAL: that is why OR-6's cross-group count is
                               zero for every operation, not only the clear-gap case. D-12 is
                               untouched: both-undefined still goes to geometry (defensive),
                               exactly-one still DENIES.
(b) INFLATED-BOX PRUNE         boxes are computed ONCE per pass (never per pair); a pair is pruned
                               only when BOTH merge conditions are PROVEN impossible — no witness
                               and no polygon at all, or the face box cannot contain the witness AND
                               the two boxes cannot hold a shared point. Slack is the predicates'
                               OWN `ON_RING_TOLERANCE` (one owner: exported from
                               `layout-face-extraction.ts`, function-local copy removed) plus a
                               1e-12 relative term for the pair's own size. Non-finite or empty
                               geometry yields no boxes and is NEVER pruned.
(c) CONTAINMENT SKIPPED WHEN   the merge gate is `inside || overlap`, so an admitted `inside` ends
    ITS OWN BOX PROVES IT      the pair AND the containment CALL itself is skipped when the witness's
    CANNOT BE INSIDE           own box proves it cannot be strictly inside the face (the overlap call
                               then still runs). A call saving, never a verdict.
(d) THE OVERLAP PREDICATE      byte-for-byte unchanged, and only reached when needed.
    IS UNCHANGED
OBSERVER (OR-6)                opt-in, test-only, never retained; counts pair subjects by D-12 class
                               and every predicate call/decision/skip, per mode. Unset = zero change.
BYPASS (OR-2)                  `disableCorrespondenceShortCircuitsForTest` restores TODAY'S evaluation
                               order verbatim (both predicates for every pair, geometry before
                               authorization, no pruning) — the differential's other side.
NO CACHE, NO BUDGET, NO RATCHET, NO CONTRACT CHANGE, NO PERSISTED STATE.
```
