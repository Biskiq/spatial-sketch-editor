## 4. Why M-2 is the blocked case (X-4), stated as a proof

```text
THE PLAN'S OWN RULE    A skipped pair needs a VERDICT, and the only sound source is M-3's identity
                       condition; a pair the condition cannot settle must be evaluated (or the
                       scope refused — the whole-document fallback).
THE MEASUREMENT        On all 11 gate rows the extent's excluded pairs and the identity condition's
                       settled pairs are the SAME SET (S4 record §3): authoring 16/16 · division
                       4/4 · merge 4/4 · retire 9/9 · (e) rows 4/4 each · (f) rows 1/1 each ·
                       replacement 1/1.
WHY IT MUST BE SO      An excluded side is structurally untouched. An untouched Room keeps its
                       boundary cycle; an untouched face keeps its key. If a face of that key is
                       owned by a Room, identity settles every pair touching it; if it is NOT owned
                       (an unowned enclosure) or the Room is NOT nameable, identity has no verdict —
                       and then M-2's own rule forbids skipping the pair. Therefore M-2's
                       exclusions are a SUBSET of M-3's settlements, and M-2's marginal saving is
                       ZERO on every disposition of the extent.
THE COST IT WOULD ADD  The extent derivation needs a BASELINE face extraction the chain path does
                       not run today (the plan priced this), plus the document diff — paid per
                       commit, to skip pairs the loop already settles with O(1) map lookups.
VERDICT                M-2 is NOT landed; the plan's allowed close applies (M-2 alone blocks M-2
                       only). M-3 landed WITHOUT it, as required. No X-4 case is hidden: this is
                       the blocked case, named, with its measurement.
WHAT WOULD UNBLOCK IT  A caller whose pass has pairs with NO identity verdict that are still
                       provably unaffected — i.e. an unowned-enclosure geometry whose proof could
                       be skipped by scope. No such caller exists in this slice; if one appears,
                       the extent derivation and its OR-3 oracle stay ready in the S4 test module.
```
