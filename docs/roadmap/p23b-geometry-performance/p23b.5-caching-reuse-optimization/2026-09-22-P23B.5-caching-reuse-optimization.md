## Contract (final, accepted)

Wall sampling options are FIXED on this path (`sampleSegment` with flatness
0.01, span 0.25, maxDepth 12, maxSamples 100,000); there is no runtime options
dimension to key or vary. The reuse contract is: artefact → inputs → key/refusal
→ owner/lifetime → exclusions, with the landed grammar (centreline OBJECT
identity + traversal + resolved canonical endpoints at full precision + Wall id)
consumed rather than re-invented. Identity implies equality only while ALL
sampled input data is unchanged. Excluded (unchanged): weakening cloning or
canonical validation, content-hash interning, generation counters, per-document
caches, derived geometry in documents or editor reactive state, a second
evaluator/key grammar, incremental compile, mesh/GPU and the wider dependency
cone (P23B.6), Worker/WASM (P23B.8), budgets.
