# Mockup provenance and prompts

Static illustrations for the [proposal](./PROPOSAL.md), generated on 2026-10-31 using the built-in image-generation tool, not the CLI/API fallback. No product code or interactive prototype was used to produce them. Output PNGs are retained in this folder's figures directory. Generative results are not guaranteed to reproduce identically.

All four final images were visually reviewed for scope, label legibility, hierarchy, selected-subject correspondence and the stated workflow. Small icon and branding differences are illustration details; the proposal and existing shell contracts govern semantics. Original requests asked for 1920 × 1200; all four actual delivered PNGs are 1586 × 992, verified from their file headers.
