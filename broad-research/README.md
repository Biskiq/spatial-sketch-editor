# Broad research

Research input for future design work. **Not** a product contract or routed authority —
`docs/README.md` and the `docs/reference/` contracts govern product truth.

| File | Contents |
| --- | --- |
| [`multi-level-spatial-authoring-ux.html`](./multi-level-spatial-authoring-ux.html) | Multi-level spatial representation and authoring UX for Museum Editor. Single self-contained file (open it directly in a browser; no network needed). Theme: Auto / Light / Dark. |

The HTML is the only source for this research. It has three views:

- **Full report** (`#/report`) — the research chapters verbatim from the original Markdown
  export, with all 83 works cited. Text-only: bracketed markers show where the three source
  figures sat. This text is canonical.
- **Interactive** (`#/interactive`) — explorable panels rebuilt from the report and from the
  two widget snapshots the Markdown had flattened to images, plus three charts (two of them
  labelled interpretive, with their evidence). Panels read the report's paragraphs and tables
  at load time — there is no second copy of the data — so they cannot drift from it.
- **Source notes** (`#/notes`) — provenance, the drift log against the earlier HTML
  synthesis, in-source variances, the widget snapshots and their transcriptions, and the
  equation transcriptions
  (eight equations were truncated by the export and are marked, not completed).
