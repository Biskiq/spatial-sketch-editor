# Broad research

Research input for future design work. **Not** a product contract or routed authority —
`docs/README.md` and the `docs/reference/` contracts govern product truth.

| File | Contents |
| --- | --- |
| [`multi-level-spatial-authoring-ux.html`](./multi-level-spatial-authoring-ux.html) | Multi-level spatial representation and authoring UX for Museum Editor. Single self-contained file (open it directly in a browser; no network needed). |

The HTML is the only source for this research. It has three views:

- **Full report** (`#/report`) — the research chapters verbatim from the original Markdown
  export, with its figures and all 83 works cited. This text is canonical.
- **Interactive** (`#/interactive`) — explorable panels rebuilt from the report and from the
  two widget snapshots the Markdown had flattened to images. Panels clone the report's
  paragraphs and tables, so they cannot drift from it.
- **Source notes** (`#/notes`) — provenance, the drift log against the earlier HTML
  synthesis, in-source variances, widget transcriptions, and the equation transcriptions
  (eight equations were truncated by the export and are marked, not completed).
